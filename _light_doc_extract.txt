1、概述
本SDK开发包提供人脸识别方案，使开发者可以迅速开发基于人脸识别的客户端软件。本文档默认读者已经掌握Android应用程序开发的相关知识。
本 SDK开发包 提供 动作+炫彩（Action + Flash）活体检测能力。相比于传统纯动作活体，炫彩活体通过在屏幕上投射不同颜色的光，采集人脸在不同光照条件下的反射数据，经过本地 SDK 算法处理后再交由服务端进行活体判断，具有更高的安全性。
动作+炫彩（ALIVEMODE_MOTION_LIGHT）模式：先要求用户完成一个随机动作（眨眼或张嘴），动作通过后再进入炫彩颜色序列采集，实现双重活体校验。
2、文档目的
本文档对炫彩活体及动作+炫彩活体的 Android SDK 接口进行使用说明，覆盖：
SDK 门面接口及参数详解
炫彩颜色序列的获取与配置
回调数据格式与服务端验证
代码示例
本文档读者为使用 Android 人脸 SDK 开发活体检测功能的产品设计师、软件工程师。

8、调用示例及数据说明

public class MainActivity extends Activity implements AEFaceInterface {

    private void startThunderAliveOneClick() {
        // 1. 初始化SDK
        AEFacePack.getInstance().AEYE_Init(this);
        // 2. 构造参数
        Bundle paras = new Bundle();
        paras.putInt(AEFaceParam.ALIVEMODE, AEFaceParam.ALIVEMODE_MOTION_LIGHT);
       paras.putString(AEFaceParam.ThunderFlashUrl, &quot;https://ai-human.a-eye.cn/xxxxx/ws&quot;);
        paras.putString(AEFaceParam.ThunderAppId, &quot;50002&quot;);
        paras.putString(AEFaceParam.ThunderAppSecret, &quot;xxxxxxxxx&quot;);
        paras.putInt(AEFaceParam.AliveSwitch, 1);
        paras.putInt(AEFaceParam.VoiceSwitch, 1);
        paras.putInt(AEFaceParam.QualitySwitch, 1);
        paras.putInt(AEFaceParam.ContinueSuccessDetectNum, 3);
        paras.putInt(AEFaceParam.ContinueFailDetectNum, 3);
        paras.putInt(AEFaceParam.SingleAliveMotionTime, 10);
        paras.putInt(AEFaceParam.ModelOverTime, 30);

        // 3. 注册回调
        AEFacePack.getInstance().AEYE_SetListener(this);
        // 4. 设置参数
        AEFacePack.getInstance().AEYE_SetParameter(paras);
        // 5.  一键启动（SDK内部: 获取颜色→活体采集→服务端验证）
        AEFacePack.getInstance().AEYE_BeginRecog(this);
        // 6. 显示加载动画
